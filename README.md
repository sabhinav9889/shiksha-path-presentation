# Shiksha Path: presentation

The talk about Shiksha Path, a learning app that works offline, in Hindi, on a shared phone, and
how it was built with Claude Code (AI Product Hackathon 2026).

| File                                                             | What it is                                                           |
| ---------------------------------------------------------------- | -------------------------------------------------------------------- |
| [`index.html`](index.html)                                       | The deck. Open it in any browser. No server, no internet needed.     |
| [`Shiksha-Path-Presentation.pdf`](Shiksha-Path-Presentation.pdf) | The same 20 slides as a PDF, for a laptop without your files.        |
| [`SPEAKER-NOTES.md`](SPEAKER-NOTES.md)                           | A talk track for each slide (about 15 minutes) and likely questions. |
| `assets/`                                                        | Phone screenshots of the live app used on the slides.                |

## Presenting

Open `index.html`, then use the arrow keys or space to move, `F` for full screen, `Home` and `End`
to jump. You can link straight to a slide, for example `index.html#12`.

## Rebuilding the PDF

Open `index.html` in Chrome, print to PDF with the paper size "1280 x 720 px", margins none and
background graphics on. The page already has print styles.

## What it covers

1. The product: the problem, the student app, the staff section.
2. The technical side: architecture, offline-first sync, engineering decisions, security and privacy,
   quality evidence.
3. How AI was used: the workflow loop, context engineering, agents and guardrails, the human in the
   loop, and what AI got wrong.
4. Honest limits, lessons learned and what happens next.

Numbers on the slides are from the submission (30 October 2026) unless a slide says otherwise.
